# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please email **security@fluidbody.ch** with:

- Description of the issue
- Steps to reproduce
- Affected component (site web, app, API)

We aim to respond within 48 hours and patch critical issues within 7 days.

## Scope

In scope:
- espace-pilates.ch, fluidbody.ch, fluidbody.app
- FluidBody+ iOS/tvOS app
- API endpoints

Out of scope:
- Social engineering
- DDoS / brute-force
- Third-party services (Stripe, Supabase, Resend, etc.)

## Bounty

We're a small team — no formal bounty program yet, but we'll acknowledge responsible disclosure publicly with consent.
