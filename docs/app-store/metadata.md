### 5.3 — Notes for the App Review team

Paste the following into the **Notes** field in App Store Connect →
App Review Information. Keep it short — Apple reviewers skim.

```
Hi Apple Review team,

Thank you for reviewing Fluidbody+ Pilates. A few notes to help:

DEMO ACCOUNT
- Email: review@fluidbody.app
- Password: ReviewApple2026!
This account has an active premium subscription (granted via RevenueCat) so
all video content unlocks without a real purchase.

KEY FLOWS TO TEST
1. Sign-in: AuthScreen > magic-link OR email/password with the demo account.
2. Browse content: tap any pilier card on the home screen; the "i" button
   opens an educational page; tap a séance to start a video.
3. Subscription paywall: when not signed in, tapping a locked séance opens
   PaywallModal. A "Restore Purchases" button is visible at the bottom.
4. Account deletion (App Store Guideline 5.1.1(v)): Profil tab > Zone
   dangereuse > Supprimer mon compte. Requires typing SUPPRIMER to confirm.
   This calls a Supabase edge function that deletes the auth user, profile,
   and associated data.
5. Apple Watch: live BPM and workout-write only run on a real device with a
   paired Watch. The app also reads Activity ring data via HealthKit for
   the Activity dashboard.
6. Languages: the app auto-detects device locale (fr, en, es, it) and can be
   changed manually in Profil > Préférences.

HEALTHKIT
The app reads HeartRate, ActiveEnergyBurned, BasalEnergyBurned,
AppleExerciseTime, AppleStandTime, BodyMass, Height, StepCount, DateOfBirth,
BiologicalSex, and Workout. It writes Workout (Pilates), ActiveEnergyBurned,
HeartRate, BodyMass, and Height. No HealthKit data is transmitted to any
external server — all reads stay on device. All permissions are optional;
the app degrades gracefully if the user declines.

PRIVACY
- Privacy Policy: https://yvan-glitch.github.io/fluidbody-privacy/
- Terms of Use: https://yvan-glitch.github.io/fluidbody-privacy/terms/
- Privacy Manifest (PrivacyInfo.xcprivacy) is included in the bundle.

EXPORT COMPLIANCE
- HTTPS only, standard system encryption.
- Answer to "Uses standard encryption" question: YES (exempt under
  category 5D992.c).

VIDEO CONTENT
Videos are served via Bunny CDN with token-authenticated URLs minted by a
Supabase edge function (sign-video-url) that verifies the user's JWT and
subscription state. The client never sees a raw CDN URL.

CONTACT
For any clarification during review: yvan@espace-pilates.ch

Thank you,
Yvan Tissot — Founder, Espace Pilates Sarl, Switzerland
```

## 7. App Privacy (data collection declarations)

Fill in App Store Connect → App Privacy. Summary of what to declare:

| Data type | Collected? | Linked to user? | Used for tracking? | Purpose |
|---|---|---|---|---|
| Email address | Yes | Yes | No | App functionality (auth) |
| User ID | Yes | Yes | No | App functionality |
| Purchase history | Yes | Yes | No | App functionality |
| Health & Fitness | No (stays on device) | — | — | — |
| Crash data | Yes (Sentry) | No (anonymous) | No | App functionality |
| Device ID | No | — | — | — |
| Advertising data | No | — | — | — |

> Note: HealthKit data is read on-device only — declare "Not Collected"
> for Health & Fitness. Sentry receives crash payloads with the user's
> Supabase UUID but the `beforeSend` hook strips email, IP, and username
> (see `App.js` Sentry init).

## 8. Pre-flight checklist

Before clicking **Submit for Review**:

- [ ] Demo account `review@fluidbody.app` created in Supabase with active
      subscription
- [ ] App icon 1024×1024 uploaded, no alpha channel, no rounded corners
- [ ] Five screenshots per device class (6.9", 6.5", 5.5") uploaded for
      iPhone, plus iPad Pro 13" screenshots
- [ ] Privacy Policy URL returns HTTP 200 from a public network
- [ ] Terms of Use URL returns HTTP 200
- [ ] Support URL returns HTTP 200 (or fall back to espace-pilates.ch/contact)
- [ ] `EXPO_PUBLIC_SENTRY_DSN` set in the production EAS build
- [ ] Latest production EAS build uploaded and processed in App Store Connect
- [ ] Test the build via TestFlight on a clean device with no prior
      Fluidbody install
- [ ] App Privacy answers filled in (see section 7)
- [ ] Notes for Reviewer pasted (see section 5.3)
- [ ] Export compliance answered (HTTPS = standard encryption, exempt)
- [ ] Pricing and availability confirmed (free + IAP, worldwide)
